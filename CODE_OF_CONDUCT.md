# Code of Conduct

Agent Blackbox is a small open-source project for developer tooling. Please keep discussion respectful, technical, and welcoming.

We expect contributors to:

- be kind and constructive
- assume good intent
- focus criticism on ideas and code, not people
- avoid harassment, insults, or discriminatory language
- respect privacy and never post secrets, credentials, or private data

Maintainers may moderate issues, pull requests, or discussions that violate these expectations.
