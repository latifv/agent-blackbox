# Changelog

## 0.1.0

First open-source release of Agent Blackbox.

Added:

- local command wrapper
- terminal log capture
- git status before/after
- git diff capture
- test command capture
- policy violation detection
- hash-chained `events.jsonl`
- static HTML report
- cheating and honest demo agents
- Codex CLI example

Limitations:

- not a full OS-level sandbox
- does not guarantee every file read or network call is captured
